# Fotos de productos

1. En GitHub entrá a esta carpeta `fotos` → **Add file → Upload files** → arrastrá la foto → **Commit changes**.
2. Nombres en minúsculas, sin espacios ni tildes, con guiones: `funda-techwoven.jpg`.
3. En el Sheets, en la columna `foto_url` (o `foto_url_2` / `foto_url_3`) poné `fotos/funda-techwoven.jpg`.
4. Ideal: JPG de 800 px de lado como máximo y menos de 200 KB.
